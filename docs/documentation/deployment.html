Deployment & Operations

Automated CI/CD via GitHub Actions. Backend deploys to Google Cloud Run (container auto-scaling), frontend to Firebase Hosting (CDN). Mobile apps built via Expo and distributed through stores.

Critical Rule: No Manual Builds

Never build manually with gcloud. All deployments must go through GitHub Actions. Push to the remote branch and let the CI/CD pipeline handle building and deploying.

Database Migrations #

Migrations are stored in packages/backend/migrations/ as SQL and Python files. They include schema changes, data seeds, and view definitions.

CategoryCountExamples

Migration Safety

Always verify database state before writing migrations: SELECT code FROM roles, SELECT column_name FROM information_schema.columns, etc. Role codes and enum values change over time and must be verified against the live database.
