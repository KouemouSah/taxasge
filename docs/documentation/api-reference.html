API Reference

The Facil backend exposes 62 API routers via FastAPI, all mounted under the /api/v1 prefix. This reference covers authentication, request conventions, and key endpoints by domain.

Base URL & Conventions #

EnvironmentBase URL
Productionhttps://taxasge-backend-staging-xrlbgdr5eq-uc.a.run.app/api/v1
Local Devhttp://localhost:8000/api/v1

Request Headers

Authorization: Bearer <access_token>
Content-Type: application/json
Accept-Language: es | fr | en    # Determines error message language

Pagination

List endpoints accept standard pagination parameters:

GET /api/v1/fiscal-services?page=1&per_page=20&sort_by=name&sort_order=asc

Response includes pagination metadata:

{
  "data": [...],
  "total": 873,
  "page": 1,
  "per_page": 20,
  "total_pages": 44
}

Authentication #

Authentication Flow
Login (email+password) → Verify credentials → 2FA check (if enabled) → Issue JWT pair
TokenLifetimePurpose
Access Token30 minutesAPI authorization (Bearer header)
Refresh Token30 daysObtain new access tokens without re-login

JWT Payload

{
  "sub": "user_uuid",
  "email": "user@example.com",
  "role": "citizen",
  "permissions": ["service_request.create", ...],
  "exp": 1714000000,
  "iat": 1713998200
}

Two-Factor Authentication (2FA)

Optional TOTP-based 2FA using pyotp. When enabled, login returns a 2fa_required flag and the client must submit the TOTP code to complete authentication.

Error Handling #

All errors follow a consistent response schema with trilingual support:

{
  "detail": "Translated error message (based on Accept-Language)",
  "error_code": "ERR_NOT_FOUND"
}
HTTP StatusError CodeDescription
400ERR_BAD_REQUESTInvalid request parameters
401ERR_UNAUTHORIZEDMissing or invalid JWT token
403ERR_FORBIDDENInsufficient permissions (RBAC)
404ERR_NOT_FOUNDResource not found
409ERR_CONFLICTResource conflict (duplicate, version mismatch)
422VALIDATION_ERRORPydantic validation failure (detailed field errors)
429ERR_RATE_LIMITEDRate limit exceeded
500ERR_SERVER_ERRORInternal error (details sanitized for clients)
Security Note

For 5xx errors, the backend sanitizes the detail field to prevent leaking internal exception messages. Full stack traces are logged server-side via Loguru.

Rate Limiting #

Rate limiting is enforced per user (or IP for unauthenticated endpoints) via the Redis-backed check_rate_limit() function.

Endpoint CategoryLimitWindow
Authentication (login/register)10 requests60 seconds
Chatbot messages30 requests60 seconds
General API (authenticated)100 requests60 seconds
File uploads20 requests60 seconds

Auth Endpoints #

POST /api/v1/auth/login Email + password login, returns JWT pair
POST /api/v1/auth/register Create new user account
POST /api/v1/auth/refresh Exchange refresh token for new access token
POST /api/v1/auth/request-verification Send email verification code
POST /api/v1/auth/password-reset Request password reset email
POST /api/v1/auth/password-change Change password (authenticated)
POST /api/v1/auth/2fa/setup Initialize TOTP 2FA setup
POST /api/v1/auth/2fa/verify Verify TOTP code during login
POST /api/v1/auth/logout Revoke refresh token

User Endpoints #

GET /api/v1/users/me Get current user profile
PUT /api/v1/users/me Update current user profile
GET /api/v1/users/{id} Get user by ID (admin)

Fiscal Services Endpoints #

GET /api/v1/fiscal-services List all fiscal services (873 total, paginated)
GET /api/v1/fiscal-services/{id} Get service details with tariff info
GET /api/v1/fiscal-services/search Full-text search (tsvector)
GET /api/v1/fiscal-services/by-ministry/{id} Services filtered by ministry

Service Requests Endpoints #

POST /api/v1/service-requests Create new service request
GET /api/v1/service-requests List user service requests
GET /api/v1/service-requests/{id} Get request details
POST /api/v1/wizard-sessions Create wizard session (cache-first flow)
PUT /api/v1/wizard-sessions/{id}/steps/{step} Update wizard step data
POST /api/v1/wizard-sessions/{id}/initiate-payment Atomic persist + payment

Payment Endpoints #

POST /api/v1/payments/initiate Initiate payment (BANGE or manual)
GET /api/v1/payments/{id} Get payment details
POST /api/v1/webhooks/bange BANGE payment callback
GET /api/v1/verify/{reference} Verify payment receipt

Chatbot Endpoints #

POST /api/v1/chatbot/message Send message to AI chatbot
GET /api/v1/chatbot/conversations List conversation history
GET /api/v1/chatbot/conversations/{id} Get conversation messages

Admin Endpoints #

GET /api/v1/admin/monitoring/health System health dashboard
GET /api/v1/admin/users List all users (admin only)
GET /api/v1/audit-logs Query audit logs (2800+ entries)
GET /api/v1/menu-config/me Get agent menu for current user
GET /api/v1/menu-config/workflow-mappings List workflow-to-menu mappings
