Database Schema Reference

PostgreSQL database hosted on Supabase with 145 tables organized across 10 domains, 50 custom enums, and pgvector extension for AI embeddings. All access via asyncpg with parameterized queries.

Migration System #

Database migrations are stored in packages/backend/migrations/ as both SQL files and Python scripts. Migrations are numbered sequentially and applied via a custom runner.

Migration Safety Rule

Always verify the database state before writing a migration. Use SELECT code FROM roles before inserting into role_permissions. Role codes like dgi_agent or ministry_agent may no longer exist — the actual codes are entity-specific (e.g., agent_cnedoge_pasaporte, agent_dgt, agent_extranjeria).

Verification Pattern

-- Check if table exists
SELECT table_name FROM information_schema.tables
WHERE table_name = 'TABLE_NAME';

-- Check columns
SELECT column_name, data_type
FROM information_schema.columns
WHERE table_name = 'TABLE_NAME';

-- Check permission exists
SELECT name FROM permissions
WHERE name = 'permission.name';
