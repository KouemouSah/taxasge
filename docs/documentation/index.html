Platform Overview

Facil is a comprehensive digital government services platform designed for the Republic of Equatorial Guinea. It enables citizens, businesses, and accountants to manage fiscal obligations, apply for civil documents, and interact with government agencies entirely online.

The platform serves multiple government entities including the Direccion General de Impuestos (DGI), CNEDOGE (passport services), Direccion General de Trafico (DGT), Extranjeria (immigration), Ayuntamiento (municipal services), Camara de Comercio, and various ministries.

Quick Start

Backend Development

# Install dependencies
pip install -r packages/backend/requirements.txt

# Configure environment
cp packages/backend/.env.example packages/backend/.env
# Edit .env with database URL, API keys, etc.

# Run development server
uvicorn app.main:app --reload

# Run tests
pytest tests/ -v

# Type checking and linting
mypy app --strict
flake8 app --max-line-length=100
black app --check

Frontend Development

# Install dependencies
cd packages/web
npm install --legacy-peer-deps

# Run development server
npm run dev

# Build for production
npm run build

# Type checking and linting
npm run type-check
npm run lint
Important

Never build manually with gcloud. All deployments must go through GitHub Actions. Push to the develop branch and the CI/CD pipeline will handle building and deploying both backend (Cloud Run) and frontend (Firebase Hosting) automatically.

Key Architecture Decisions

DecisionChoiceRationale
API Framework FastAPI (async) Native async, auto OpenAPI docs, Pydantic v2 validation, high throughput
Database Driver asyncpg (not ORM) Raw parameterized SQL for maximum control, performance, and security
Frontend Routing Next.js App Router with [locale] Server-side rendering, built-in i18n, route groups for auth/dashboard/public
State Management React Query + Zustand Server state (Query) vs client state (Zustand) separation
Deployment Cloud Run + Firebase Hosting Serverless scaling, zero infra management, CDN distribution
Entity Routing Database-driven (entities.workflow_codes) No code changes needed to assign workflows to entities, admin UI managed
Cache Strategy HybridCache (Redis + in-memory fallback) Graceful degradation if Redis unavailable, domain-specific TTLs
AI Model Gemini 2.5 Flash via Vertex AI Fast inference, tool-use support, cost-effective for government workloads
