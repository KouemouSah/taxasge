## Untranslatable / Keep as-is

These are kept in their original form across all languages for technical accuracy:

- Brand names: **Facil**, **TaxasGE**, **Sah Kouemou**, **Grafana**, **Sentry**, **LogRocket**, **Looker Studio**, **Supabase**, **Cloud Run**, **Firebase**, **Vertex AI**, **Gemini**, **Expo**, **Next.js**, **React**, **FastAPI**, **PostgreSQL**, **MySQL**, **BigQuery**, **Snowflake**, **MSSQL**, **Redis**, **Upstash**, **BANGE**, **EAS**.
- Code identifiers: function names, class names, file paths, env var names, SQL identifiers, JSON keys.
- Standard acronyms when commonly used: **JWT**, **RBAC**, **CRUD**, **REST**, **API**, **SDK**, **CDN**, **CI/CD**, **IAM**, **SLA**, **OMS**, **MV**, **JSONB**, **SSL/TLS**, **DSN**, **SVG**, **PNG**, **PDF**, **HTTP/HTTPS**, **JSON**, **YAML**, **CSV**.
- Country / city names in their canonical form: **Equatorial Guinea / Guinée équatoriale / Guinea Ecuatorial**, **Malabo**, **Bata**, **Mongomo** (no translation needed).
- Currency code: **XAF** (kept as code, not translated).
- Date format: ISO `2026-05-04` everywhere; long-form dates translate the month name only.

## Tone & register

- **EN**: technical, dense, direct. Sentences can be short ("No row-level security on Grafana.").
- **FR**: same density, but use formal technical register ("Aucune sécurité au niveau ligne sur Grafana." — note the inversion vs literal "Pas de sécurité..."). Avoid colloquialisms.
- **ES**: same density, neutral Spanish (Spain/LatAm-compatible — avoid `vosotros`, `che`, etc.). Tutoyer/ustedes choice: **usted** for formal admin docs.

When translating a heading: keep capitalization style (Title Case in EN → Phrase case in FR/ES per native conventions).

When a concept has no good FR/ES equivalent, **keep the English term in italics** the first time it appears, then translate parenthetically: "*session replay* (rejeu de session)" — afterwards use the FR/ES form alone.
