AI & Intelligence

Facil integrates AI across four domains: a RAG chatbot with 35 tools, OCR document intelligence with 40 schemas, smart agent assignment, and content enrichment. All powered by Google Vertex AI (Gemini 2.5 Flash) and pgvector embeddings.

Hybrid Search Pipeline #

Search combines semantic (vector) and lexical (full-text) approaches with configurable weights:

ComponentWeightTechnologyIndex
Semantic Search70%pgvector cosine similarity (<=> operator)IVFFlat index on embedding column
Full-Text Search30%PostgreSQL tsvector/tsquery (ts_rank)GIN index on tsvector column
 
-- Hybrid search query (simplified)
SELECT id, title, content,
  (0.7 * (1 - (embedding <=> $1)) + 0.3 * ts_rank(tsv, to_tsquery($2))) AS score
FROM fiscal_services
WHERE embedding <=> $1 < 0.8
   OR tsv @@ to_tsquery($2)
ORDER BY score DESC
LIMIT 10

Confidentiality Boundaries

Each agent role has strict data access boundaries enforced at the tool level. A Citizen Agent cannot access any internal data, even if the prompt attempts to trick it. Treasury Agents can only see data for their assigned entity.

Self-Reflection Loop #

After generating a response, the chatbot evaluates its own answer quality on a 1-10 scale. If the score is below 5, it regenerates with adjusted context. This ensures response quality remains consistently high.

Generate Response → Self-Score (1-10) → Score ≥ 5? → Return
Score < 5 → Regenerate → Return (max 1 retry)

15 Response Formats

The chatbot outputs responses in structured formats appropriate to the query type, including service cards, procedure lists, fee breakdowns, status updates, document checklists, appointment information, and general information blocks.

OCR Document Intelligence #

40 Document Schemas

Each document type has a JSON schema defining extraction fields, bounding box coordinates, and validation rules. Schemas are stored in packages/backend/app/modules/service_requests/schemas/.

OCR Data Access Rule

OCR-extracted fields must use context.get_extracted_field(doc, path). Form-submitted fields use form_data.get(). Never mix these two access patterns.

AI Security (OWASP) #

The chatbot implements OWASP LLM Top 10 mitigations including prompt injection detection with 30+ pattern rules. See Security Architecture for details.

Content Enrichment #

The enrichment module uses Gemini to automatically generate rich descriptions for fiscal services. Each description is 600 characters, structured in 3 paragraphs, with a self-evaluation score and few-shot examples for consistent quality.
