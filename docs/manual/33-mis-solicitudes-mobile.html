Mis solicitudes (Móvil)

Lista de todas sus solicitudes con filtros táctiles, FAB (Floating Action Button) para crear una nueva, y acceso al detalle por simple toque. Versión simplificada y optimizada del dashboard de seguimiento.

Para: Ciudadano Empresa
En esta página
  • 1. Acceder a la lista
  • 2. Filtros y FAB
  • 3. Lista de solicitudes
  • 4. Detalle de una solicitud
  • 5. Diferencias con la versión Web

1. Acceder a la lista

2 caminos: Panel principal → tarjeta «Mis Solicitudes» o menú hamburguesa → «Mis Solicitudes».

2. Filtros y FAB

En la parte superior, una barra de filtros horizontales (chips) permite alternar entre estados:

  • Ver todo — muestra todas las solicitudes
  • Enviada — esperando validación
  • En proceso — agente revisando
  • En revisión — agente solicita info adicional

En la parte inferior derecha, un FAB (Floating Action Button) verde con el icono «+ Nueva Solicitud» permite lanzar el wizard directamente sin volver al panel.

3. Lista de solicitudes

Cada línea muestra:

  • Icono del trámite a la izquierda (passeport, conducir, etc.)
  • Título corto + referencia (ex. CON-2026-00001)
  • Badge estado con color (azul=Enviada, naranja=Procesando, verde=Completada, rojo=Rechazada)
  • Fecha de última actualización
  • Pulse la línea para abrir el detalle

4. Detalle de una solicitud (vista móvil)

La pantalla de detalle muestra los mismos elementos que la versión Web (cf. page 23) con adaptaciones móviles:

  • Stepper vertical (en lugar de horizontal) — más fácil de leer en pantalla pequeña
  • Tabs deslizables entre Resumen / Documentos / Pagos
  • CTA «Compartir» nativo (WhatsApp, SMS, email)
  • CTA «Descargar PDF» con guardado en la galería del teléfono
  • Pull-to-refresh — desliza hacia abajo para refrescar el estado
