Encontrar mi perfil

Cada perfil tiene un recorrido distinto en Facil. Seleccione el suyo para ir directamente a las páginas que le conciernen.

👨
Ciudadano
Particular que realiza trámites administrativos para sí mismo (pasaporte, conducir, residencia, IRPF...).
🏢
Representante de empresa
Persona que representa o gestiona una o más empresas (licencias comerciales, IVA, IS, obligaciones).
📋
Contable
Profesional contable que gestiona declaraciones fiscales y trámites para múltiples clientes.
👨‍⚖️
Agente público
Funcionario o agente de un ministerio (CNEDOGE, DGT, Tesoro, Extranjería, Ayuntamiento, Cámara, MIN OMS) que valida solicitudes.
👤
Supervisor
Responsable de un equipo de agentes, gestiona escaladas, reparto de trabajo y desempeño.
⚙
Administrador
Administrador técnico de la plataforma — usuarios, roles, catálogo, comunicaciones, configuración.
🔍
Visitante (sin cuenta)
Persona sin cuenta que solo consulta servicios, calculadora, simulador o verifica un recibo.

Web vs Móvil

Facil se utiliza tanto en navegador como en aplicación móvil Android/iOS. Cada plataforma cubre casos de uso ligeramente diferentes.

💻

Versión Web

Acceso completo: ciudadanos, empresas, contables, agentes, supervisores, administradores. Pantalla completa, dashboards detallados.

https://taxasge.emacsah.com
📱

Aplicación Móvil

Optimizada para ciudadanos y empresas en movilidad. Notificaciones push, biometría, modo sin conexión, escaneo QR.
