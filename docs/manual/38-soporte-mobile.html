Soporte (Móvil)

Sistema de tickets de soporte en la app móvil — lista compacta de sus tickets con badge estado/prioridad, FAB para crear un nuevo, notifications push automáticas a cada respuesta del agente de soporte.

Para: Ciudadano Empresa
En esta página
  • 1. Lista de tickets
  • 2. Filtros + FAB nuevo ticket
  • 3. Detalle del ticket + push notifications
  • 4. Diferencias con la versión Web

1. Lista de tickets

Acceso : Panel principal → tarjeta «Soporte» o menú hamburguesa → «Soporte». La pantalla muestra una lista vertical de cards con vos tickets.

2. Filtros + FAB nuevo ticket

Chips horizontales en la parte superior:

  • Todos — todos sus tickets
  • Abiertos — tickets esperando respuesta
  • Resueltos — agente respondió, espera confirmación
  • Cerrados — definitivos, no reabribles

El FAB (+ Nuevo ticket) abre el formulario simplificado para crear un ticket: categoría, asunto, descripción, prioridad. Posibilidad de adjuntar capturas de pantalla directamente desde la galería.

3. Detalle del ticket + push notifications

Toque un ticket para abrir su detalle. Vista de tipo «conversación» (similar à WhatsApp) con sus mensajes y los del agente alternándose. Posibilidad de adjuntar nuevas capturas en cada respuesta.

A cada respuesta del agente, recibe una push notification en su teléfono (icono Facil + extracto del mensaje). Toque la notificación para abrir directamente el ticket concernido.

Atención

Los tickets cerrados no son reabribles. Si su problema persiste, cree un nuevo ticket haciendo referencia al SUP- anterior en la descripción para conservar el contexto.

4. Diferencias con la versión Web
