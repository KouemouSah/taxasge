Agente DGT: licencia de conducir (factorizado)

El agente DGT (Dirección General de Tráfico Rodado y Seguridad Vial) sigue el patrón común agentes workflows simples descrito en detalle en la página 62, donde la licencia de conducir es justamente el ejemplo detallado elegido para ilustrar el patrón. Esta página resume la especificidad DGT y remite a la página 62 para el patrón completo, las acciones, las permisos y las claves del workflow.

1. Resumen de la especificidad DGT

Workflow Python : ConducirWorkflow (app/modules/service_requests/workflows/conducir_workflow.py). Entidad : DGT. 5 workflow_codes : CONDUCIR_NUEVO, CONDUCIR_CANJE, CONDUCIR_RENOVACION, CONDUCIR_DUPLICADO, CONDUCIR_EXTENSION. 7 clases de licencia (A, B, B+, C, D, E, F) con edades mínimas (18 o 21 años según la clase). Pago directo Mobile Money (sin Nota de Ingreso intermedia). RDV obligatorio para CONDUCIR_NUEVO (examen práctico) o para el retrait del carnet en otros casos.
