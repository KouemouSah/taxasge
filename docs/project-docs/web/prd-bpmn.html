Vue couplée : User Story ↔ Workflow BPMN

Sélectionnez une user story ou un workflow. La vue couplée affiche automatiquement l'élément correspondant. Cross-links bidirectionnels.

User Story (PRD)

Aucune user story sélectionnée. Choisissez-en une dans le sélecteur ci-dessus, ou un workflow pour afficher automatiquement les user stories liées.

Workflow BPMN

Aucun workflow sélectionné. Choisissez-en un dans le sélecteur ci-dessus, ou une user story pour afficher automatiquement le workflow lié.

Comment ça marche

  • Sélection user story → affiche les détails et le premier workflow BPMN lié rendu inline.
  • Sélection workflow → affiche le diagramme Mermaid et la liste des user stories liées.
  • Cross-links dans chaque panneau pour basculer rapidement vers l'autre.
  • URL deep-link : prd-bpmn.html?us=US-002&wf=01-declaration-iva ouvre directement la paire.
