Product Requirements Document — Facil

Version 1.0 — 2026-05-11. Audience : équipe produit, technique, partenaires institutionnels, advisors. Maturité : MVP avancé pre-launch.

1. Executive Summary

Pitch

Facil est la plateforme native souveraine de transformation digitale fiscale pour les administrations publiques émergentes — première instance déployée en Guinée Équatoriale, conçue pour s'étendre à la région CEMAC / UEMOA / OHADA.

Statut actuel

  • OK : MVP avancé — 31 modules backend (en code), 42 modules frontend, 77 tables PostgreSQL, 25 enums, 300+ migrations
  • OK : Observabilité production (Grafana Cloud + AI + Security Observability)
  • OK : Code production-ready, infrastructure Cloud Run + Firebase + Supabase opérationnelle

2. Vision et stratégie

5 défis structurels

  1. Mobilisation des recettes fiscales sous-optimale (procédures papier, files d'attente)
  2. Fragmentation des systèmes (chaque ministère cloisonné)
  3. Absence de traçabilité numérique (pas d'audit trail immuable)
  4. Faible inclusion financière (80%+ sans compte bancaire mais 60%+ mobile money)
  5. Charges opérationnelles administratives élevées

6 piliers Facil — schéma hub-and-spoke

Catalogue centralisé 850+ services fiscaux + 28 types de déclarations.
Inspection terrain App mobile + tablet inspector avec collecte de paiement et sync offline.
Paiement multi-canal BANGE Mobile Money + USSD GETESA / MUNI + cartes + virements + cash.
Chatbot IA Vertex AI Gemini RAG, 24/7, multilingue ES / FR / EN.
OCR + observabilité Gemini extraction documents + Grafana Cloud production-grade.
App mobile citoyen Application native iOS / Android (Expo) avec notifications push, mode offline et accès USSD.

10. Out of scope V1

Ce qu'on ne fait PAS pour rester focus (planifié V1.1+ via Facil Framework) :

  • Blockchain Hyperledger Fabric — palliatif Postgres+Trillian+Rekor (V1.1 Phase P)
  • Sage X3 connector — V2 via V1.1 Phase O
  • eIDAS qualifié national — V2 via V1.1 N.5 ext
  • ISO 20022 banking gateway — V2 via V1.1 Phase R
  • Active Directory direct — V2 via V1.1 J ext (SAML disponible V1)
  • Keycloak intégré — V2 optionnel via V1.1 J Keycloak ext
  • Biométrie passeport / KYC renforcé — V2 si demande client
  • Marketplace de services tiers — V2+
  • Multi-tenant strict — V2 via Facil multi-tenant
  • Certification formelle ISO 27001 / SOC 2 — V2 (chantier 12-18 mois)
