Documentation interactive : Product Requirements Document (PRD), processus métier BPMN, et vue couplée user stories ↔ workflows. Première instance déployée en Guinée Équatoriale, conçue pour s'étendre à la région CEMAC / UEMOA / OHADA.

6 piliers de la solution

Catalogue centralisé 850+ services fiscaux + 28 types de déclarations (IVA, IRPF, retenciones, petroliferos).
Inspection terrain App mobile + tablet inspector avec collecte de paiement et sync offline.
Paiement multi-canal BANGE Mobile Money + USSD GETESA / MUNI + cartes + virements + cash.
Chatbot IA Vertex AI Gemini RAG, 24/7, multilingue ES / FR / EN.
OCR + observabilité Gemini extraction documents + Grafana Cloud production-grade.
App mobile citoyen Application native iOS / Android (Expo) avec notifications push, mode offline et accès USSD.
