## Vector-icon fonts (separate from JS bundle)

The biggest single area of *embedded but unused* weight is the
`@expo/vector-icons` font set. The package ships **all** icon families as
`.ttf` assets in the APK regardless of usage:

| Font | Size |
|------|-----:|
| MaterialCommunityIcons.ttf | 1.31 MB *(used everywhere — keep)* |
| Ionicons.ttf | 390 KB *(unused)* |
| MaterialIcons.ttf | 357 KB *(unused)* |
| Fontisto.ttf | 314 KB *(unused)* |
| FontAwesome.ttf | ~178 KB *(unused — present per default install)* |
| Octicons.ttf | 69 KB *(unused)* |
| Foundation.ttf | 57 KB *(unused)* |
| SimpleLineIcons.ttf | 54 KB *(unused)* |
| Zocial.ttf | 26 KB *(unused)* |
| Other small families | ~80 KB combined *(unused)* |
| **Total embedded** | **~2.8 MB** |
| **Effectively used** | **~1.31 MB (MaterialCommunityIcons only)** |

**Verified by grep**: every `import { … } from '@expo/vector-icons'` in
`src/` only pulls `MaterialCommunityIcons`. No other family is referenced
from app code.

**Why we don't strip them in this pass** — `react-native-paper` uses
`MaterialCommunityIcons` via the `icon="…"` prop API at runtime (works fine
because that's the family we keep). But Paper *also* exposes the option to
pass `icon={({ color, size }) => <Ionicons … />}` and a few of its built-in
themes can request other families. Stripping fonts requires:
1. Wiring `expo-font` with an explicit allow-list and disabling auto-loading.
2. Auditing `node_modules/react-native-paper/lib/module/components/**` for any
   non-MCI icon reference.
3. Retesting every screen on device (loose font stripping breaks silently —
   icons render as `?` boxes).

→ **Reported, not actioned.** Estimated win: ~1.3-1.5 MB on the APK after
stripping. Tracked for V1.1 hardening.

## Other observations

- **Lottie JSON** in `assets/animations/` (~539 KB combined) is already
  serialized without whitespace; no further gain there (verified during P8.2
  perf pass).
- **PNG assets** in `assets/images/` were optimised in commit
  `0574c5d0` — saved 1.0 MB (-88%) via Pillow re-encoding.
- **node_modules** disk size is 3.7 GB but that's irrelevant for the shipped
  APK — only what Metro bundles (and the Expo asset selection) lands in
  production.

## How to re-run

```bash
cd packages/mobile
bash ../../.claude/analyze-mobile-bundle.sh
```

The script regenerates `.bundle-analysis/bundle-report.json` and prints the
top-30 packages. Re-run after big dependency adds to spot regressions.
