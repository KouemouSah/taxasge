## Notes pour les releases suivantes

- **Patch (1.0.x → 1.0.x+1)** : lister 1-3 bugfixes courts. Format suggéré : *« Corrections : (1) X, (2) Y, (3) Z. Mejoras de rendimiento. »*
- **Minor (1.0 → 1.1)** : annoncer la fonctionnalité majeure. Format : *« Nuevo : <feature>. Otras mejoras y correcciones. »*
- **Major (1.x → 2.0)** : storytelling court. Format : *« Facil 2.0 trae <X grandes cambios>. <CTA>. »*

Garder le ton positif, pas de jargon technique. Les release notes apparaissent dans la fiche Play Store sous *« Nouveautés »* — c'est un signal de fraîcheur pour Google, à mettre à jour à chaque release.
